# Estruturas Repetitivas

Nesta seção pratico a repetição de instruções utilizando as estruturas de repetição da linguagem Java.

## Conteúdos estudados

* `while`
* `for`
* `do-while`
* Contadores
* Validação de entrada com repetição
* Estruturas de repetição aplicadas a problemas práticos

## Estrutura da pasta

* **exemplos/** → exemplos apresentados durante as aulas.
* **exercicios/** → exercícios resolvidos durante os estudos.
* **mini-projetos/** → pequenos projetos desenvolvidos para praticar os conceitos estudados.

## Mini projetos

### Gerador de Tabuada

Prática com `for`, utilizando contadores e intervalos definidos pelo usuário.

### Caixa Eletrônico Simples

Prática com `while`, `switch-case` e validação de entradas para operações de depósito e saque.

### Jogo de Adivinhação

Prática com `do-while`, `if/else`, contadores e geração de números aleatórios utilizando `Random`.

## Objetivo

Aprender a utilizar estruturas de repetição para controlar fluxos de execução, validar entradas e desenvolver soluções para problemas que exigem repetição.
