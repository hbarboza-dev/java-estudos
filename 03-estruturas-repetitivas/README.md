# Estruturas Repetitivas

Nesta seção pratiquei a repetição de instruções utilizando as estruturas de repetição da linguagem Java.

## Conteúdos estudados

- while
- for
- do-while
- Contadores
- Acumuladores
- Estruturas de repetição aninhadas
- Controle de laços (`break` e `continue`)
- Validação de entrada com repetição

## Estrutura da pasta

- **exemplos/** → exemplos apresentados durante as aulas.
- **exercicios/** → exercícios resolvidos do curso.
- **mini-projetos/** → pequenos projetos para praticar os conceitos estudados.
