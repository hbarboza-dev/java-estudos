# Estrutura Condicional

Nesta seção pratiquei a tomada de decisões utilizando estruturas condicionais da linguagem Java.

## Conteúdos estudados

- if
- else
- else if
- switch case
- Operadores relacionais
- Operadores lógicos (`&&`, `||` e `!`)
- Expressões booleanas

## Estrutura da pasta

- **exemplos/** → exemplos apresentados durante as aulas.
- **exercicios/** → exercícios resolvidos do curso.
- **mini-projetos/** → pequenos projetos aplicando os conceitos estudados.

## Mini projetos

- Sistema de Aprovação
- Caixa Eletrônico

## Objetivo

Aprender a controlar o fluxo de execução do programa com base em diferentes condições.
